This is a simulation of code that will be used to develop ML classifier based on NACC data
To run this code:
1) download VS code (OR use any platform to run the code)
2) download Git (to clone the repository)
3) clone the project by
   - open VS code
   - click "Terminal" in VS bar
   - click "New terminal"
   - write "git clone https://github.com/bobalqasem-crypto/ad-ftd-ENC.git" in terminal
4) write "cd ad-ftd-ENC" to enter the project environment
5) write "python -m venv .venv" to create a virtual environment 
7) write "pip install -r requirements.txt" to downloads all required libraries for the code
8) wait till it is DONE
9) write "python data/generate_data.py" to create MOCK data 
10) write "python src/train_model.py" to develop ML prediction model & show you the results of its internal & external validations
